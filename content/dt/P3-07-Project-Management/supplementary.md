# Supplementary Materials

The read-along reference for this episode. Nothing here is spoken — it reinforces the tools, the
Gantt chart, the factors, the worked example and the model answers.

### Listing 1 — What management is
```text
MANAGEMENT = directing RESOURCES (time, money, materials, people) to achieve the project's GOALS,
so each task is done at the RIGHT TIME and in the RIGHT SEQUENCE.

Plan -> Implement -> Evaluate (monitor & adjust). Management is ONGOING, not a one-off plan.
```

### Listing 2 — The management tools (the three plans = ATF, + journal)
| Tool | Purpose |
|---|---|
| **A**ction plan | List EVERY task (brainstorm/mind map) so none is forgotten — the first step |
| **T**ime plan = **Gantt chart** | Schedule tasks against a timeline (start/duration/end); sequence; monitor |
| **F**inance plan | Budget all costs; track spending; keep within budget |
| Journal / diary | Ongoing record (ideas, sketches, decisions, meetings) = ongoing evaluation |

> The three plans are formalised in Year 12 (H5.1) as **Action, Time, Finance** plans (ATF).

### Listing 3 — The Gantt chart (most examinable tool)
```text
A GANTT CHART = a grid: tasks down the side, TIME across the top; each task is a BAR showing
start date, duration, end date.

It handles DEPENDENCIES:
  - Dependent tasks: must finish before another starts (build BEFORE paint).
  - Simultaneous tasks: can run in parallel (research + sketch at once).
  - CRITICAL PATH = the longest chain of dependent tasks -> sets the project's MINIMUM duration.
    A delay on the critical path delays the WHOLE project.

Used to PLAN (sequence) and MONITOR (actual vs planned -> re-plan when tasks slip).
```

### Listing 4 — Factors affecting management (RV GS-CDT D)
```text
Logical flow (easier than the bare list):
  Resources   - identify what's available
  Values      - clarify what matters for this project
  Goals       - set them
  Standards   - set them
  Costs/benefits - evaluate each alternative
  Decisions   - make & implement them
  Tasks       - describe & sequence them
  Documentation - of the plans
```

### Listing 5 — Worked example: a 4-week build project
```text
GANTT (tasks x time):
  Wk1: research ideas      ====        (parallel)
       sketch concepts     ====        (parallel)
  Wk2: finalise design         ====    (depends on sketches)
       order materials             ==  (depends on design)
  Wk3: build prototype              ====(depends on materials)  <- CRITICAL PATH
  Wk4: test / refine / present          ====

FINANCE PLAN (budget $70):
  materials $40 + tool hire $20 + printing $10 = $70  -> track ACTUAL vs budget.

If materials are delayed, the Gantt shows build + everything after slipping -> re-plan.
```

### Listing 6 — Headline question: "How are management tools used to plan AND monitor?"
```text
WEAK answer (caps low): "I made a timeline." -> names a tool, no monitoring.

STRONG answer (band ~6):
  - Action plan lists every task (none forgotten).
  - Gantt chart sequences tasks vs time (dependencies, parallel tasks, critical path) AND monitors
    actual vs planned -> re-plan when a task slips.
  - Finance plan tracks costs vs budget.
  KEY WORD: MONITOR — management is continual, not just planning at the start.
```

### Listing 7 — Model answers to the closing exam questions
```text
Q1 (3 marks) — Three management tools + purpose.
  Action plan (list all tasks); Gantt chart (schedule tasks vs time; monitor); finance plan (budget &
  track costs). [or journal — ongoing record/evaluation]. Pair each with its purpose.

Q2 (4 marks) — Importance of a Gantt chart.
  Schedules tasks vs time (start/duration/end); shows dependencies & parallel tasks -> efficient
  sequencing; identifies the critical path (sets minimum duration); used to MONITOR actual vs planned
  & re-plan. (Critical path + monitoring = full marks.)

Q3 (2 marks) — Four factors affecting management.
  Any 4: available resources; clarify values; set goals; set standards; evaluate costs/benefits; make
  & implement decisions; task descriptions & sequencing; documentation. [RV GS-CDT D]

Q4 (3 marks) — Why is management ongoing, not a single step?
  Plans change (tasks slip, materials delayed, costs change). Skill = plan/implement/EVALUATE: monitor
  actual progress vs the Gantt & spending vs the finance plan, and adjust to stay on track.
```

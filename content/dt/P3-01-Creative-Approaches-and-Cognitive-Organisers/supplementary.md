# Supplementary Materials

The read-along reference for this episode. Nothing here is spoken — it reinforces the creativity
mindset, the organisers, SCAMPER, the worked example and the model answers.

### Listing 1 — Creativity is a process; creative vs critical thinking
```text
KEY POINT: Creativity is NOT effortless inspiration. It requires self-discipline, dedication and
deliberate technique. It is a trainable skill and a STAGE of the design process (Ideate), not a gift.

CREATIVE thinking  = GENERATIVE — produces new ideas, lots of them ("outside the square")
CRITICAL thinking  = EVALUATIVE — judges the quality/validity/suitability of ideas
-> complementary: generate freely first, then judge. Designers do both throughout the process.
```

### Listing 2 — Cognitive organisers (visual thinking tools)
| Organiser | What it does | Generate or evaluate? |
|---|---|---|
| Mind map | Central idea with radiating branches — generate & connect ideas | Generate |
| Flowchart | Map a sequence or process | Structure |
| Decision matrix | Table comparing options against criteria | Evaluate |
| Venn diagram | Compare/overlap concepts | Compare |
| PMI chart | Plus / Minus / Interesting — weigh an idea | Evaluate |

> "Select and apply a variety" = choose the right organiser for the task (mind map to generate,
> decision matrix to choose). A material decision matrix vs CPA FACE criteria is a cognitive
> organiser doing material selection.

### Listing 3 — SCAMPER: seven prompts to generate ideas from an existing design
| Letter | Prompt | Example (backpack) |
|---|---|---|
| **S** | Substitute (material/part/process) | Lighter waterproof fabric instead of canvas |
| **C** | Combine (merge two things) | Bag + built-in charger / fold-out seat |
| **A** | Adapt (to a new use/context) | Borrow hiking-pack back support |
| **M** | Modify (size/shape/attributes; magnify/minify) | Bigger laptop pocket; reshaped to sit better |
| **P** | Put to another use | Converts into a sports/shopping bag |
| **E** | Eliminate (remove/simplify) | Minimalist, fewer zips, lighter |
| **R** | Reverse / Rearrange | Opens from the back for security; loads from the bottom |

### Listing 4 — Ideation strategies (all break "design fixation")
```text
Brainstorming        - many ideas fast; NO judging during the session; quantity over quality
SCAMPER              - structured 7-prompt checklist on an existing design (Listing 3)
Lateral thinking     - approach the problem from an unexpected angle to break habit
Morphological analysis - break the problem into parts, list options per part, recombine

Common principle: defeat DESIGN FIXATION (latching onto the first idea). Quantity before quality,
THEN evaluate critically.
```

### Listing 5 — Worked example: SCAMPER on "improve a school backpack"
```text
S - lighter waterproof fabric instead of canvas
C - integrate a charger / fold-out seat
A - adopt hiking-pack back-support straps
M - add compartments; reshape; magnify the laptop pocket
P - converts into a sports or shopping bag
E - strip back zips/weight -> minimalist version
R - opens from the back (security); loads from the bottom

7 prompts -> a dozen ideas, none of them the obvious "make it bigger". Writing out a few prompts
WITH the ideas they produced = a strong exam answer.
```

### Listing 6 — Headline question: "Describe a technique to generate creative ideas"
```text
WEAK answer (caps low):
  "I used brainstorming to think of ideas." -> names, doesn't explain, shows no ideas.

STRONG answer (band ~6):
  - NAME the technique (e.g. SCAMPER).
  - EXPLAIN how it works to break fixation / force new angles.
  - SHOW the ideas it actually produced.
```

### Listing 7 — Model answers to the closing exam questions
```text
Q1 (2 marks) — What is a cognitive organiser? Two examples.
  A visual tool to structure thinking (organise info, explore a problem, generate/compare ideas).
  E.g. mind map (generate) + decision matrix (evaluate).

Q2 (4 marks) — How does SCAMPER generate creative ideas?
  Applies 7 prompts to an existing design: Substitute, Combine, Adapt, Modify, Put to another use,
  Eliminate, Reverse. E.g. backpack: Combine -> built-in charger; Eliminate -> minimalist version.
  Forces past the obvious first idea (breaks fixation). Name prompts + show results.

Q3 (3 marks) — Why is creativity a process, not just talent?
  Relies on discipline + deliberate techniques (SCAMPER, brainstorming, organisers), not effortless
  inspiration. Techniques can be learned & applied by anyone -> trainable -> a stage of the process
  (Ideate), not a gift.

Q4 (2 marks) — Distinguish creative vs critical thinking.
  Creative = generative (produces new ideas). Critical = evaluative (judges ideas). Complementary:
  generate first, then judge.
```

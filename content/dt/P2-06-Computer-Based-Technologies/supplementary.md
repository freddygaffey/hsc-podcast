# Supplementary Materials

The read-along reference for this episode. Nothing here is spoken — it reinforces the five
applications, the CAD→CAM chain, the discriminate verb, the worked example and the model answers.

### Listing 1 — The five applications (MR SCP)
| Application | What it does | Real tool / example |
|---|---|---|
| **M**odelling | Build & develop a design (mathematical + 3D); rotate, assemble, change on screen | CAD: AutoCAD, SketchUp, FreeCAD |
| **R**esearch | Gather information digitally | Online databases, specs, market data |
| **S**imulation & graphics | Test a design virtually (stress, airflow, heat) without a physical prototype; render images | Engineering simulation packages; rendering software |
| **C**ommunication | Share files, collaborate remotely, communicate ideas | Cloud files, email, collaborative CAD |
| **P**resentation | Present the finished design to clients/stakeholders | Renders, animations, virtual walkthroughs, slideshows |

> Benefit to emphasise: CAD lets you **test on screen without time-consuming model-making**;
> simulation **replaces physical prototypes** → saves time, cost and materials.

### Listing 2 — The digital chain: CAD → CAM → 3D printing
```text
CAD (computer-aided design)  -- build & test the model on screen
   |
   v
CAM (computer-aided manufacturing)  -- the model drives the machines
   |
   v
CNC machining / 3D printing (rapid prototyping)  -- the object is made layer by layer / cut

=> the digital link from SCREEN to OBJECT; the boundary where designing meets producing.
   (3D printing = great for one-off prototypes; CAM = precise mass production.)
```

### Listing 3 — "Discriminate" = choose the RIGHT tool for the task
```text
DISCRIMINATE (the syllabus verb) = select the appropriate technology, not "computers for everything".

  Good discrimination: CAD + simulation to test a complex mechanism before building.
  Poor discrimination: 3D-printing a part you could cut from card in 2 minutes.

A strong answer MATCHES tool to task and states the BENEFIT — it does not just list software.
```

### Listing 4 — Worked example: MR SCP applied to designing a chair
| Application | What you do |
|---|---|
| Modelling | Build the chair in CAD; rotate; adjust dimensions on screen |
| Research | Gather ergonomic data & existing chair designs online |
| Simulation | Load-test the digital model (holds a person's weight) — no physical prototype yet |
| Graphics | Render a photorealistic image in the chosen finish |
| Communication | Share the CAD file with a manufacturer/collaborator |
| Presentation | Show the client a rendered walkthrough/animation |

> Then CAD → CAM: send the file to a 3D printer / CNC machine to make a prototype or final part.
> Headline benefit: simulation tested the design **before anything physical existed**.

### Listing 5 — Headline question: "technology & communication barriers" (2022)
```text
WEAK answer (caps low):
  "Designers use computers to communicate." -> no barrier, no specific technology.

STRONG answer (band ~6) — name the BARRIER, then the TECHNOLOGY that removes it:
  - Distance        -> shared cloud files / collaborative CAD (one live model, real time)
  - Understanding   -> 3D rendered model / virtual walkthrough (a client who can't read drawings)
  - Language        -> visual/graphical communication (less word-dependent)
  + judge that the appropriate technology is chosen for each barrier.
```

### Listing 6 — Model answers to the closing exam questions
```text
Q1 (3 marks) — Three applications of computer-based technologies.
  Any 3 of MR SCP: modelling (3D CAD), research (online sources), simulation & graphics (virtual
  testing/rendering), communication (file sharing/collaboration), presentation (renders to clients).
  Name a real tool for each.

Q2 (3 marks) — One benefit of simulation.
  Tests performance virtually (load, airflow) using a model, not a physical prototype -> problems
  fixed on screen before using material -> saves time, cost, waste; many variations tested fast.

Q3 (5 marks) — How does technology overcome communication barriers?
  Distance -> cloud files/collaborative CAD; understanding -> 3D renders/walkthroughs for clients who
  can't read drawings; language -> visual/graphical communication. Choose the right tech per barrier.
  (Name the barrier AND the specific technology.)

Q4 (3 marks) — What is "discriminating" in tech choice, and why does it matter?
  Choosing the appropriate technology for the task (not computers for everything). Matters because
  the right tool adds value (efficiency/accuracy) while the wrong one wastes time/resources.
  E.g. CAD/simulation for a complex mechanism vs a hand sketch for a rough early idea.

Q5 (4 marks) — Compare a computer model with a physical model.
  Computer (CAD): on-screen 3D, rotate/change instantly, simulate without material, fast/cheap to
  revise, shareable. Physical: tangible — real scale, weight, texture, ergonomics a screen can't
  fully convey; slower/costlier to make & change. Complementary: model/simulate digitally to refine
  cheaply, then build a physical prototype to verify real-world feel. (They combine, not replace.)
```

# Supplementary Materials

The read-along reference for this episode. Nothing here is spoken — it reinforces the brief, the
parameters/criteria distinction, the worked brief and the model answers.

### Listing 1 — The design brief = Need + Constraints + Criteria (NCC)
```text
A DESIGN BRIEF = a statement of the problem/need + the parameters + the criteria the solution
must meet. Formulated by ANALYSING the need (confirm it's genuine — often via market research).

It is the CONTRACT that directs the whole project and the BENCHMARK the final design is judged on.

  N - Need (the problem to solve, for whom)
  C - Constraints / parameters (the limits)
  C - Criteria for success (the measurable must-haves)
```

### Listing 2 — Parameters vs criteria (the examinable distinction)
| | Parameter | Criterion for success |
|---|---|---|
| What it is | A limit/boundary the design MUST comply with | A must-have that defines a successful design |
| Source | Usually INHERITED — outside the designer's control | SET by the designer/client |
| Lamp example | Height; base diameter; 240 V; globe socket type | Touch switch; contemporary style; recycled materials |
| In one line | The boundaries you work WITHIN | The success measures you're judged AGAINST |

### Listing 3 — Criteria come in two kinds (both should be MEASURABLE)
```text
FUNCTIONAL criteria - what the design must DO       (maps to the FUNCTION factor)
AESTHETIC criteria  - how the design must LOOK/appeal (maps to the AESTHETICS factor)

MEASURABLE/checkable is essential -> so evaluation is objective.
  Weak (can't evaluate): "should be good quality / look nice"
  Strong (testable):     "must hold 750 mL and not leak when inverted"; "must cost under $25"
```

### Listing 4 — Open vs closed briefs
| | Open brief | Closed brief |
|---|---|---|
| Specification | General need; broad interpretation | Tightly specified parameters & criteria |
| Designer freedom | High (creative scope) | Low (clear direction) |
| Trade-off | More creativity, less direction | More direction, less creativity |

> Most real briefs sit between. An open brief leaves more room for ideation tools like SCAMPER.

### Listing 5 — Worked example: a design brief for a reusable drink bottle
```text
NEED: a durable, leak-proof, reusable bottle to cut single-use plastic, for active adults.

PARAMETERS (inherited limits):
  - fits a standard car cup-holder
  - complies with food-safety standards
  - under a set retail price

CRITERIA FOR SUCCESS (measurable must-haves):
  Functional: holds 750 mL; doesn't leak when inverted; keeps a drink cold >= 6 hours
  Aesthetic:  premium look; range of colours for the target market

-> Every criterion is checkable, so the bottle can be objectively evaluated against the brief later.
```

### Listing 6 — Headline question + model answers
```text
"Explain the purpose of a design brief / why criteria should be measurable"
  WEAK: "A brief says what to make." -> thin, caps low.
  STRONG: brief = need + parameters + criteria; directs the project; ensures appropriateness;
          measurable criteria -> objective evaluation; brief & final evaluation are bookends.
```

### Listing 7 — Model answers to the closing exam questions
```text
Q1 (2 marks) — What is a design brief?
  A statement of the need + the parameters & criteria the solution must meet; formulated by
  analysing the need; directs the project and is the benchmark for evaluation.

Q2 (3 marks) — Distinguish parameter vs criterion (example).
  Parameter = inherited limit (e.g. lamp must run on 240 V / standard socket). Criterion = set
  success must-have (e.g. touch switch, contemporary style), measurable. Inherited boundary vs set
  success measure.

Q3 (5 marks) — Purpose of a brief + why criteria must be measurable.
  Brief defines need/parameters/criteria, directs every stage, ensures appropriateness. Measurable
  criteria -> objective evaluation (e.g. "holds 750 mL, no leak" testable; "good quality" not). Brief
  & final evaluation are bookends.

Q4 (2 marks) — Distinguish open vs closed brief.
  Open = general need, broad freedom (more creativity, less direction). Closed = tightly specified
  parameters/criteria (more direction, less creativity). Trade-off: freedom vs direction.
```

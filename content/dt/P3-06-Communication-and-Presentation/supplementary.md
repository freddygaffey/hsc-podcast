# Supplementary Materials

The read-along reference for this episode. Nothing here is spoken — it reinforces the
communication model, forms, criteria, visualising, the worked example and the model answers.

### Listing 1 — The communication process (SMMR) + barriers
```text
SENDER -> MESSAGE -> MEDIUM -> RECEIVER          (+ FEEDBACK back to the sender)

The key question: "Has my message been RECEIVED and UNDERSTOOD?"

BARRIER (noise) = anything that interferes with the message getting through clearly:
  - too-technical a drawing for the audience
  - poorly worded message
  - physical distance / language gap
```

### Listing 2 — Forms of communication (V-WGVA)
| Form | Example |
|---|---|
| Verbal | Spoken pitch to a client |
| Written | Design specification, report |
| Graphical | Chart/diagram of data |
| Visual | Sketch, render, image, model |
| Audio | Sound |

> Designers usually COMBINE forms; experiment to find the best for the message + audience.

### Listing 3 — Criteria for evaluating/justifying communication (CAE)
```text
Clarity              - is the message clear and unambiguous?
Appropriateness      - is the method suited to the audience and purpose?
Ease of interpretation - can the receiver understand it without effort?

Use CAE to JUSTIFY a choice: e.g. an orthographic drawing = high clarity for an engineer but low
ease of interpretation for a layperson client -> not appropriate for them.
```

### Listing 4 — Visualising solutions (rough → polished) and their audiences
| Visual form | What it is | Best for |
|---|---|---|
| Sketch | Quick freehand idea | Early ideation; self/team |
| Orthographic drawing | Formal, dimensioned views | The manufacturer (precise) |
| Rendered drawing | Realistic shaded image | The client (selling the look) |
| Model / prototype | 3D physical or digital representation | Client/team — AND testing |

> Purpose of a prototype/model = DUAL: communicate the design in 3D **and** test/evaluate it.

### Listing 5 — Worked example: one chair, four communication methods
| Method | Communicates | To whom | Limitation |
|---|---|---|---|
| Sketch | Rough concept, fast | Self / team (early) | Imprecise |
| Orthographic drawing | Exact dimensions | Manufacturer | Hard for a layperson to read |
| Rendered image | How it will look | Client | Not buildable from |
| Model / prototype | 3D form; testable | Client / team | Time/cost to make |

> Same chair, four methods — each chosen for its audience & purpose, judged by CAE.

### Listing 6 — Headline question: technology & communication barriers (via SMMR)
```text
WEAK answer (caps low): "They just use computers." -> no barrier, no specific fix.

STRONG answer (band ~6) — locate the barrier in SMMR, choose the form/tech, judge by CAE:
  - Distance (sender<->receiver) -> videoconferencing / shared cloud files
  - Receiver can't interpret      -> 3D render / virtual walkthrough (raises ease of interpretation)
  - Language                      -> visual rather than written forms
```

### Listing 7 — Model answers to the closing exam questions
```text
Q1 (2 marks) — Four elements of the communication process.
  Sender, message, medium, receiver (+ feedback). [SMMR; barrier = noise.]

Q2 (3 marks) — Three forms of communication + examples.
  Any 3 of V-WGVA: visual (sketch/render), written (spec/report), verbal (pitch), graphical (chart),
  audio. For designers, the visual forms matter most.

Q3 (5 marks) — Select & justify a communication technique for a client.
  Match to audience/message/purpose; justify via clarity/appropriateness/ease. For a non-technical
  client: orthographic = inappropriate (hard to interpret); choose a render/3D model/walkthrough —
  clear, easy to interpret, appropriate. Contrast with the less-appropriate option.

Q4 (2 marks) — Purpose of a model/prototype in communicating a design.
  Communicates the design in 3D (form/scale/function a flat drawing can't) AND allows testing/
  evaluation. (Dual purpose.)

Q5 (3 marks) — Why use several forms of communication in one project?
  Different stages/audiences/messages need different forms: sketches (team, early), orthographic
  (manufacturer, dimensions), renders/models (client, look), written spec (technical record).
  Combining/experimenting ensures each message meets clarity/appropriateness/ease for its audience.
```

| **V-WGVA** | Verbal, Written, Graphical, Visual, Audio | The forms of communication a designer can use (P5.2) |

# Glossary — Acronyms & Mnemonics

Every acronym, initialism and named mnemonic used across the Software Engineering
supplementary material, with its expansion and meaning. Each episode that uses one or
more of these terms repeats the relevant rows in a `## Glossary` section at its foot.

## Mnemonics & principles
Standard, widely recognised mnemonics.

| Mnemonic | Stands for | What it's for |
|---|---|---|
| **AAA** | Authentication · Authorisation · Accountability | The three access-security pillars: prove who you are, check what you may do, and keep a traceable record |
| **ACID** | Atomicity · Consistency · Isolation · Durability | The four properties that guarantee a database transaction is processed reliably |
| **CIA** | Confidentiality · Integrity · Availability | The three core information-security properties (the security triad) |
| **CRUD** | Create · Read · Update · Delete | The four basic operations performed on stored (database) records |
| **LIFO** | Last In · First Out | Access order of a stack: the most recently added item is removed first |
| **POUR** | Perceivable · Operable · Understandable · Robust | The four WCAG accessibility principles for web content |
| **Sense-Think-Act** | Sense · Think · Act | The repeating control loop of an autonomous / mechatronic system |
| **STRIDE** | Spoofing · Tampering · Repudiation · Information disclosure · Denial of service · Elevation of privilege | The six threat categories used in threat modelling |

## Acronyms & abbreviations
| Term | Expansion | Meaning |
|---|---|---|
| 2FA | Two-Factor Authentication | Requiring two independent pieces of evidence to log in (e.g. password plus a code) |
| AES | Advanced Encryption Standard | The standard symmetric-key algorithm for encrypting data |
| AI | Artificial Intelligence | Software that performs tasks normally needing human intelligence |
| API | Application Programming Interface | A defined contract that lets one piece of software request services from another |
| APP | Australian Privacy Principles | The 13 principles governing how organisations handle personal information under Australian law |
| BPA | Business Process Automation | Automating whole multi-step business workflows, not just single tasks |
| BSD | Berkeley Software Distribution (licence) | A permissive open-source software licence |
| CDN | Content Delivery Network | Geographically distributed servers that cache and serve content close to the user |
| CI/CD | Continuous Integration / Continuous Deployment (Delivery) | Automating the build-test-deploy pipeline so changes ship frequently and safely |
| CMS | Content Management System | Software for creating and managing website content without hand-coding each page |
| COMPAS | Correctional Offender Management Profiling for Alternative Sanctions | A risk-assessment algorithm used in US courts (case study in algorithmic bias) |
| CORS | Cross-Origin Resource Sharing | Browser rules controlling when a page may request resources from another origin |
| CPU | Central Processing Unit | The processor that executes program instructions |
| CR | Code Review | Manual inspection of source code by other developers to catch defects |
| CSRF | Cross-Site Request Forgery | An attack that tricks a logged-in user's browser into sending an unwanted request |
| CSS | Cascading Style Sheets | The language that styles and lays out HTML content |
| CSV | Comma-Separated Values | A plain-text file format storing tabular data as comma-delimited rows |
| CVE | Common Vulnerabilities and Exposures | A public catalogue giving each known security flaw a unique identifier |
| CVSS | Common Vulnerability Scoring System | A standard 0-10 score rating the severity of a security vulnerability |
| DARPA | Defense Advanced Research Projects Agency | The US defence R&D agency (ran the autonomous-vehicle Grand Challenge) |
| DAST | Dynamic Application Security Testing | Testing a running application from the outside for security flaws ("doing") |
| DB | Database | An organised, queryable store of persistent data |
| DDoS | Distributed Denial of Service | Overwhelming a service with traffic from many machines so it becomes unavailable |
| DevOps | Development and Operations | A culture/practice uniting development and operations to automate delivery |
| DFD | Data Flow Diagram | A model showing how data moves between processes, stores and external entities |
| DNS | Domain Name System | The system that translates human-readable domain names into IP addresses |
| DOF | Degrees Of Freedom | The number of independent movements a mechatronic system (e.g. a robot arm) can make |
| FK | Foreign Key | A column that references the primary key of another table to link records |
| FTP | File Transfer Protocol | A protocol for transferring files between hosts (insecure unless secured) |
| GB | Gigabyte | A unit of data storage (about one billion bytes) |
| GDPR | General Data Protection Regulation | The European Union's data-protection and privacy law |
| GPA | Grade Point Average | A numeric summary of academic grades (used as example data) |
| GPL | GNU General Public License | A copyleft open-source licence requiring derivative works to stay open |
| HMAC | Hash-based Message Authentication Code | A keyed hash proving a message's integrity and authenticity |
| HTML | HyperText Markup Language | The language that structures the content of web pages |
| HTTP | HyperText Transfer Protocol | The request/response protocol used to transfer web resources |
| HTTPS | HyperText Transfer Protocol Secure | HTTP encrypted with TLS for confidentiality and integrity in transit |
| IDE | Integrated Development Environment | An editor bundling coding, building, running and debugging tools in one program |
| IoT | Internet of Things | Everyday physical devices (cameras, sensors) connected to the internet |
| IP | Intellectual Property | Creations of the mind (code, designs, content) protected by copyright, patents and trademarks |
| IP | Internet Protocol | The protocol that addresses and routes data packets across networks |
| JPL | Jet Propulsion Laboratory | NASA's centre for robotic space missions (Mars Climate Orbiter case study) |
| JS | JavaScript | The programming language that runs in web browsers |
| JSON | JavaScript Object Notation | A lightweight, human-readable text format for exchanging structured data |
| JWT | JSON Web Token | A compact, signed token used to carry authentication/authorisation claims |
| MCAS | Maneuvering Characteristics Augmentation System | The flight-control software implicated in the Boeing 737 MAX crashes |
| MFA | Multi-Factor Authentication | Requiring two or more independent factors to verify identity |
| MGF1 | Mask Generation Function 1 | The mask-generation function used inside RSA OAEP/PSS padding |
| MIT | Massachusetts Institute of Technology | In licensing, the MIT License — a short, permissive open-source licence; also the US university it is named after |
| ML | Machine Learning | AI systems that learn patterns from data rather than being explicitly programmed |
| MTTD | Mean Time To Detect | The average time taken to notice a security incident |
| MTTR | Mean Time To Respond (Recover) | The average time taken to respond to and recover from an incident |
| NASA | National Aeronautics and Space Administration | The US space agency (referenced in several engineering-failure case studies) |
| NESA | NSW Education Standards Authority | The body that sets the HSC syllabus and exams in New South Wales |
| NFR | Non-Functional Requirement | A quality constraint (performance, security, usability) rather than a feature |
| NIST | National Institute of Standards and Technology | The US agency that publishes widely used security standards and frameworks |
| OAEP | Optimal Asymmetric Encryption Padding | The secure padding scheme used with RSA encryption |
| OOP | Object-Oriented Programming | A paradigm structuring software around objects that bundle data and behaviour |
| ORM | Object-Relational Mapping | A layer that maps database tables to program objects so you write code, not raw SQL |
| OSS | Open-Source Software | Software whose source code is publicly available and licensed for reuse |
| PCI | Payment Card Industry (Data Security Standard) | The security standard for organisations that handle payment-card data |
| PEN | Penetration test | An authorised simulated attack that chains real exploits to prove impact |
| PIA | Privacy Impact Assessment | A structured review of how a project affects personal privacy |
| PID | Proportional-Integral-Derivative (controller) | A closed-loop control algorithm that corrects error smoothly toward a setpoint |
| PK | Primary Key | The column that uniquely identifies each row in a database table |
| PSS | Probabilistic Signature Scheme | The secure padding scheme used with RSA digital signatures |
| PWA | Progressive Web App | A website that can install, work offline and behave like a native app |
| QA | Quality Assurance | The processes that build quality into a product, not just test for defects |
| RBAC | Role-Based Access Control | Granting permissions to roles, then assigning users to those roles |
| ROI | Return on Investment | The financial gain from an investment relative to its cost |
| RPA | Robotic Process Automation | Software 'bots' that automate repetitive, rule-based user tasks |
| RSA | Rivest-Shamir-Adleman | A widely used asymmetric (public-key) encryption and signature algorithm |
| SAST | Static Application Security Testing | Analysing source code for security flaws without running it ("source") |
| SDLC | Software Development Life Cycle | The staged process (requirements → design → build → test → maintain) for building software |
| SFTP | SSH File Transfer Protocol | A secure, encrypted protocol for transferring files over SSH |
| SHA-256 | Secure Hash Algorithm, 256-bit | A cryptographic hash producing a fixed 256-bit fingerprint of data |
| SMB | Server Message Block | A network file-sharing protocol (exploited by WannaCry) |
| SPA | Single-Page Application | A web app that loads one page and updates content dynamically via JavaScript |
| SQL | Structured Query Language | The standard language for querying and manipulating relational databases |
| SQLi | SQL injection | An attack that injects malicious SQL through unvalidated input |
| SSH | Secure Shell | An encrypted protocol for remote login and command execution |
| SSL | Secure Sockets Layer | The predecessor to TLS for encrypting network connections |
| TCP | Transmission Control Protocol | The protocol providing reliable, ordered delivery of data over IP |
| TLS | Transport Layer Security | The protocol that encrypts and authenticates data in transit (secures HTTPS) |
| TOCTOU | Time-Of-Check to Time-Of-Use | A race-condition flaw where state changes between validating and using it |
| UAT | User Acceptance Testing | Final testing by end users to confirm the software meets their needs |
| UI | User Interface | The parts of a system a user directly interacts with |
| URL | Uniform Resource Locator | The address that identifies and locates a resource on the web |
| USD | United States Dollars | The currency unit used in cost/impact figures |
| UTC | Coordinated Universal Time | The primary global time standard, used for unambiguous timestamps |
| UX | User Experience | The overall quality of a user's interaction with a product |
| VA | Vulnerability Assessment | Systematically scanning and cataloguing known weaknesses (breadth over depth) |
| VPN | Virtual Private Network | An encrypted tunnel that extends a private network across a public one |
| W3C | World Wide Web Consortium | The body that develops open web standards (HTML, CSS, WCAG) |
| WAF | Web Application Firewall | A filter that inspects HTTP traffic to block web attacks |
| WAI | Web Accessibility Initiative | The W3C effort that produces web accessibility guidelines |
| WCAG | Web Content Accessibility Guidelines | The W3C standard defining how to make web content accessible (see POUR) |
| XSS | Cross-Site Scripting | An attack injecting malicious scripts into pages viewed by other users |
| Y2K | Year 2000 (bug) | The bug from storing years as two digits, feared to break systems in 2000 |
